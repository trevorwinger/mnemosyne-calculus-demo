# Bundled textbook notice

`assets/apex-calculus-5e.pdf.zip` contains an unchanged copy of **APEX Calculus**, dated June 11, 2026, by Gregory Hartman with Sean Fitzpatrick, Alex Jordan, and Carly Vollet as editors.

The source text states that it is licensed to the public under the [Creative Commons Attribution–NonCommercial 4.0 International license](https://creativecommons.org/licenses/by-nc/4.0/). This repository redistributes the file only as part of a noncommercial teaching prototype and preserves this attribution and license notice. Do not use the bundled file for commercial purposes. See the license and attribution pages in the PDF for the original notice.

The application does not serve the PDF to students. At bootstrap it extracts the archive into a Git-ignored local folder and preprocesses a limited set of Calculus I sections for private local retrieval.
